# Unlim Cloud — Native Android (Unofficial)

Telegram-এর **Saved Messages**-কে ক্লাউড স্টোরেজ বানিয়ে ফাইল আপলোড / ডাউনলোড / মোছার একটি
**সম্পূর্ণ নেটিভ** Android অ্যাপ (Kotlin + Jetpack Compose + অফিসিয়াল [TDLib](https://github.com/tdlib/td))।
WebView নেই। ধারণাটি [inulute/unlim-cloud](https://github.com/inulute/unlim-cloud) (MIT) থেকে নেওয়া; এটি অফিসিয়াল অ্যাপ নয়।

## ফিচার
- নিজের ফোন নম্বর + কোড (+ 2FA পাসওয়ার্ড) দিয়ে Telegram লগইন
- Saved Messages-এ থাকা ফাইলের তালিকা (সব / ডকুমেন্ট / ছবি-ভিডিও / অডিও), পেজিনেশনসহ
- একাধিক ফাইল আপলোড (ডকুমেন্ট হিসেবে, মূল কোয়ালিটি অক্ষত), অগ্রগতি দেখা
- নিচে ৪টি ট্যাব: **Gallery**, **Folders**, **Download** (আপলোড/ডাউনলোড দেখা), **Menu** (সেটিংস ও লগআউট)
- ফোল্ডার: ফাইলের ক্যাপশনে `📁 নাম` লেখা হয়, তাই Telegram অ্যাপেও ক্যাপশন দেখা যায়; ফোল্ডার তৈরি, নাম বদল, মোছা (ফাইল মুছে না), ফাইল সরানো
- উপরে স্ট্যাটাস আইকন: সবুজ গোল রিং + ↓/↑ তীর; ব্যর্থ হলে লাল (!)
- নিচে টেনে রিফ্রেশ
- থাম্বনেইলসহ তালিকা ও গ্রিড ভিউ (প্রতি লাইনে ২/৩/৪/৫টি); থাম্বনেইল না থাকলে ফাইলের ধরন অনুযায়ী রঙিন আইকন, আর লোড হওয়ার আগে কম-রেজোলিউশনের প্রিভিউ
- ফাইলে চাপ দিলে: **খুলুন** (ডাউনলোড ছাড়াই অন্য অ্যাপে), **শেয়ার**, **Downloads-এ সংরক্ষণ**, **মুছুন**
- নাম দিয়ে খোঁজা; ক্রম: তারিখ / নাম / সাইজ (উভয় দিকে)
- দীর্ঘক্ষণ চেপে একাধিক ফাইল নির্বাচন → একসাথে ডাউনলোড বা মোছা
- ডাউনলোড → ফোনের `Downloads` ফোল্ডারে
- ফাইল মোছা, লগআউট

## ডিজাইন (Liquid Glass)
- বাটন, চিপ, টুলবার, নিচের নেভিগেশন, FAB, ডায়ালগ, কার্ড ও মেনু স্বচ্ছ "গ্লাস" ধাঁচে (ঝাপসা ব্যাকড্রপ, হাইলাইট বর্ডার, প্রতিফলন, গ্লো)
- নির্বাচিত ট্যাবে আলোকিত গ্লাস-পিল, যা ট্যাব বদলালে পিছলে যায়
- ব্যাকগ্রাউন্ড: গ্যালারির ছবি / গ্রেডিয়েন্ট / ডিফল্ট; ব্লার, উজ্জ্বলতা, গ্লাস-স্বচ্ছতা, ছবির ফিট (Cover/Contain/Center), রিসেট; সব সেটিং ফোনে সংরক্ষিত ও সাথে সাথে প্রয়োগ হয় (Menu → ডিজাইন ও ব্যাকগ্রাউন্ড)
- লাইট/ডার্ক/অটো থিম; ব্যাকগ্রাউন্ডের উজ্জ্বলতা মেপে লেখা পড়ার উপযোগী রাখতে স্বয়ংক্রিয় আবরণ

## আগে একবার করুন: Telegram API credentials
1. https://my.telegram.org এ নিজের নম্বর দিয়ে লগইন করুন।
2. **API development tools** → একটি অ্যাপ তৈরি করুন → `api_id` ও `api_hash` কপি করুন।
3. অ্যাপ প্রথমবার খুললে এ দুটি বসাবেন। এগুলো কোডে বা GitHub-এ রাখার দরকার নেই, শুধু আপনার ফোনে সংরক্ষিত থাকে।

## GitHub Actions দিয়ে APK বানানো
1. এই ফোল্ডারের সবকিছু (`.github` ফোল্ডারসহ) একটি GitHub repository-তে push করুন।
2. **Actions** ট্যাবে "Build Android APK" চলবে (না চললে "Run workflow")।
3. **প্রথমবার ৪০–৯০ মিনিট লাগবে**, কারণ Telegram-এর অফিসিয়াল সোর্স থেকে TDLib কম্পাইল হয়। এরপর cache থেকে কয়েক মিনিটে হয়ে যায়।
4. শেষে run-এর পাতা থেকে **UnlimCloud-apk** artifact ডাউনলোড করে APK ইনস্টল করুন।

> TDLib আবার নতুন করে build করাতে চাইলে `build-apk.yml`-এ `TDLIB_CACHE_VERSION` সংখ্যাটি বাড়িয়ে দিন।

## স্থায়ী signing key (আপডেট ইনস্টলের জন্য)
repo-র **Settings → Secrets and variables → Actions**-এ চারটি secret দিন: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`। এরপর প্রতিটি নতুন APK আগেরটির ওপর সরাসরি আপডেট হবে, লগইন হারাবে না।
build লগে "Show signing certificate" ধাপের SHA-256 প্রতিবার একই থাকলে key ঠিক আছে।
keystore ফাইল বা পাসওয়ার্ড কখনও repo-তে রাখবেন না।

## সীমাবদ্ধতা
- ওয়েবসাইটের (unlim-cloud.web.app) নিজস্ব ফোল্ডার-কাঠামো অজানা, তাই এখানে ফোল্ডার নেই; সব ফাইল একটি তালিকায় দেখায়।
- একটি ফাইল সর্বোচ্চ ২ GB (Telegram Premium হলে ৪ GB)।
- আপলোডের আগে ফাইল অ্যাপের ক্যাশে একবার কপি হয় (TDLib `content://` ঠিকানা পড়তে পারে না); আপলোড শেষে কপি মুছে যায়। কপি একটার পর একটা চলে ও অগ্রগতি দেখায়।
- অ্যাপ বন্ধ করে দিলে চলমান বড় আপলোড থেমে যেতে পারে।
- TDLib-এর লোকাল ডেটাবেস এনক্রিপ্ট করা নয় (অ্যাপের private স্টোরেজে থাকে)।
